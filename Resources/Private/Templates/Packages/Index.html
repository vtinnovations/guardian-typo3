The shared V-T.ONE licence screen: one section per installed V-T.ONE product, rendered from the registry. Nothing here is Guardian-specific — a second product's section is produced by the same markup from its own state. Each section carries all three administrator actions: activate an entered key, update the record already held, and remove it. The state below every heading is server-rendered, so the screen never sits in a loading state waiting for a request that might not arrive; the script only replaces it after an action.
